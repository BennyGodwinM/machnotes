# Scratch

Personal working material — real slide decks, drafts, notes — as opposed to
`../templates/`, which holds clean starting points to copy from.

Nothing in here is read by the website; it's just files in the repo for git
history and VS Code access. Organize however's useful:

- `slides/` — presentations (copy `../templates/slides.typ` to start one)
- `docs/` — documents/notes (copy `../templates/document.typ` to start one)

Compile locally with the Typst extension or `typst compile <file>.typ`.
